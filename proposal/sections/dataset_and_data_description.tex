\section{Dataset and Data Description}

For the intended research, the Visual Genome dataset will be used. The Visual Genome
dataset is a large-scale image-language dataset designed to connect visual information with 
structured natural-language annotations. It consists of 108,077 images, 1,773,258 visual question-answer pairs and
5,406,939 region descriptions \parencite{krishna2017visual}. This is ideal for the intended research since the dataset is perfectly
suited for the visual OPSD technique of providing the teacher with privileged regional cropped information \parencite{yuan2026vision}.

For this research, a subset of approximately 5000 image-question-answer instances will be sampled. The subset with be appropriately divided
into training, validation and test partitions. The official Visual Genome dataset is open source and available 
to download from the following URL: \href{https://homes.cs.washington.edu/~ranjay/visualgenome/index.html}{Visual Genome Website}.
